## Limitacions conegudes

* **Programació Orientada a Objectes (Classes i herència):** Per falta de temps no s'ha implementat la classe base `Exercici` ni la subclasse amb `extends` per al càlcul especialitzat de calories en exercicis de cardio quan s'entrenen més de 3 dies a la setmana.
* **Disseny visual (CSS):** S'ha aplicat un estil bàsic i responsiu (mòbil i escriptori) prioritzant la funcionalitat, la llegibilitat i l'accessibilitat per damunt de l'acabat estètic.
* **Casos límit i proves visuals:** Tot i que el flux principal i les validacions funcionen correctament, queden pendents proves més exhaustives d'ajust visual en diferents mides de pantalla, linies o icones.
